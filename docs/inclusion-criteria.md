# Scope

This collection covers inference acceleration for autoregressive image and visual generation. It includes execution optimizations for existing models and efficient generator designs with reported inference-cost results.

Image generation, video generation and 3D/motion synthesis have separate collections. Training-only improvements and visual-understanding acceleration are outside the main list. Memory savings and component-level runtime retain their stated measurement scope.

Workshop-only publications are excluded. Background papers and papers awaiting classification appear in separate lists.
