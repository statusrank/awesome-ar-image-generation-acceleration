# Contributing

Suggest papers through an issue or pull request. Include the full title, venue and a stable paper link. Describe the acceleration mechanism and cite its relevant section or experiment.

The collection covers autoregressive image and visual generation. Image, video and 3D tasks are listed separately. Workshop-only papers are excluded. Background and pending papers remain outside the acceleration-paper count.

Edit `data/papers.json`, then run `python scripts/render.py` and `python scripts/validate.py`. Preserve the paper's title and publication metadata. Include official code links when available.

Documentation and catalog contributions use CC BY 4.0. Maintenance scripts use MIT. Linked papers retain their own licenses.
